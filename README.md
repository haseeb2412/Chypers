## 👨‍💻 How to Use Each Cipher

Each cipher section in the app lets users:

1. 🔐 Input plaintext
2. 🔑 Provide a key (if required)
3. ➡️ Encrypt or decrypt text
4. 📋 Copy the result

All logic is handled via JavaScript functions for quick demonstration.

## 🌍 Run on Localhost

To run this project locally, follow these steps:

### 🧰 Prerequisites

- Node.js and npm installed (if using modules)
- A code editor like VS Code

### 🛠️ Setup Instructions

```bash
# 1. Clone the repo
git clone https://github.com/haseeb2412/chypers.git

# 2. Go to the project directory
cd chypers

# 3. (Optional) If using npm modules
npm install

# 4. Start your project
# If it's just HTML/JS, open index.html in your browser
# If using a simple HTTP server:
npx serve
# or
npm install -g live-server
live-server
